## 1. この演習で何をするか

Python を使って、コンピュータの記録（ログ）から「いつもと違う動き」を見つける**小さなセキュリティ監視プログラム**を作ります。
5 つのテーマから 1 つをチームで担当します。

| テーマ | Notebook の章 | 最初の問い |
| --- | --- | --- |
| C-1A ネットワーク探索・異常通信の検出 | 第4章 | どのコンピュータが異常に多く通信しているか？ |
| C-1B 不正認証・アカウント悪用の検出 | 第5章 | どのユーザーが何度もログインに失敗しているか？ |
| C-1C Web・APIへの不正アクセスの検出 | 第6章 | どの Web リクエストに通常と違う特徴があるか？ |
| C-1D 不正操作・システム改変の検出 | 第7章 | どのファイルが追加・削除・変更されたか？ |
| C-1E 情報流出・異常データ転送の検出 | 第8章 | どのコンピュータが異常に大量のデータを送信しているか？ |

各テーマは同じ 5 つの STEP と 3 つのレベルでできています。

| レベル | STEP | 内容 |
| --- | --- | --- |
| **Level 1：基本課題（必須）** | STEP 1〜3 | 小さなデータで、異常の候補を見つけるプログラムを完成させる |
| Level 2：改良課題（推奨） | STEP 4 | 辞書・集合で改良し、実行時間と計算量を比べる |
| Level 3：発展課題（選択） | STEP 5 | 公開データへの適用、時間窓、検出性能の評価、独自機能 |

## 2. はじめ方

### 自分の PC（VS Code）で使う場合

1. リポジトリを取得します（**Notebook だけでなく、data フォルダを含む一式**が必要です）。
2. VS Code で `c1-web-attack-detection/C1_cybersecurity_starter.ipynb` を開きます。
3. 右上の「カーネルの選択」で Python 3.11〜3.13 を選びます（`ipykernel` が必要です）。
4. **第0章〜第3章**を上から順に実行し、次に**担当テーマの章**を実行します。

グラフを表示したい場合だけ、`pip install -r requirements.txt` で matplotlib を入れてください。
基本課題は Python の標準ライブラリだけで実行できます。

## 4. 実行時の表示の意味

| 表示 | 意味 |
| --- | --- |
| `[未実装]` | まだその関数を作っていない。エラーではありません |
| `[OK]` | 期待される結果と一致した |
| `[NG]` | 作った関数の結果が期待と違う（バグがある） |
| `[注意] ファイルが見つかりません` | data フォルダの場所が違う。2 章を読み直す |

## 5. 倫理・法律上の注意

- 許可なく実際のネットワークやコンピュータを調べる（スキャンする）ことは、不正アクセス禁止法などに違反するおそれがあります。
- データ内の攻撃に似た文字列は**ただの文字列**です。実行したり、Web サイトに送ったりしてはいけません。
- この演習で見つけるのは「**調べる必要がある候補**」です。「攻撃者を特定した」とは言えません。
- 人工データでうまく検出できても、実際の環境で同じように検出できるとは限りません。
