# C-1：サイバー攻撃の検出

**― ネットワーク・Web・API・システムを対象としたセキュリティ監視システムの開発 ―**

プログラミング演習Ⅰ チーム開発課題（C-1 Cybersecurity Programming Starter）

> 🛡️ **この教材の目的は「防御・監視」です。** 使うデータは、教材用の人工データと、保存済みのログだけです。
> 実際のネットワークを調べる（スキャンする）、Web サイトに攻撃のようなリクエストを送る、他人のアカウントでログインを試す、などは**絶対に行わないでください**（法律に違反するおそれがあります）。

## まず読んでください

- この教材には **5 つのテーマ**があります。**チームは担当する 1 つのテーマだけ**に取り組みます。
- 全 5 テーマを順番に読む必要はありません。**共通の章（第0〜3章）と、担当テーマの章**を実行します。
- **Level 1** を完成させると、基本的なセキュリティ監視プログラムができます。
- **Level 2** で、そのプログラムを改良します。
- その後、チームで考えた**独自の機能**を作り、結果を発表します（`TASKS.md`）。

## 1. 演習の目的

コンピュータの記録（ログ）から「いつもと違う動き」を見つけるプログラムを、Python で作ります。
セキュリティの専門知識は必要ありません。for 文・if 文・関数・リスト・辞書・集合・文字列・CSV の読み込みを使って、
**現実の問題を、Python で解ける小さな問題に分けて解く**ことが目的です。

## 2. 5 つのテーマ

| テーマ | Notebook の章 | 最初の問い |
| --- | --- | --- |
| C-1A ネットワーク探索・異常通信の検出 | 第4章 | どのコンピュータが異常に多く通信しているか？ |

| C-1E 情報流出・異常データ転送の検出 | 第8章 | どのコンピュータが異常に大量のデータを送信しているか？ |

## 7. 編集するセル

**編集するのは【学生実装課題】のセルだけ**です。それ以外のセルは実行するだけです。
`raise NotImplementedError("学生実装課題")` の行を消して、自分のコードを書きます。

## 8. 動作確認の見方

| 表示 | 意味 | どうするか |
| --- | --- | --- |
| `[OK]` | 期待される結果と一致した | 次の課題へ |
| `[未実装]` | まだ書いていない（エラーではありません） | 関数を実装する |
| `[NG]` | 実行できたが、結果が違う | 「違い」の説明を読み、処理を見直す |
| `[エラー]` | 実行中にエラーが起きた | 表示された「場所」の行を見直す |

動作確認は、Mini Dataset（数件）と Tiny Dataset（数十件）の 2 回あります。両方 `[OK]` になれば完成です。

## 9. よくあるエラーと対処

| 症状 | 原因と対処 |
| --- | --- |
| `NameError: name 'check' is not defined` など | 第3章（3.7・3.8）のセルを実行していません。第1章から順に実行し直します |
| `[注意] data フォルダが見つかりません` | フォルダ全体ではなく Notebook だけを開いています。フォルダ全体を開くか、Colab では `%cd` で教材のフォルダに移動します |
| `[NG]` で「型が違います … return を書き忘れていませんか？」 | 関数の最後に `return` がありません |
| `[エラー]` で `KeyError` | 列名のつづりが違います（例：`"src_ip"`）。データの表示を見て確かめます |
| `[エラー]` で `TypeError: … str and int` | 数値が文字列のままです。CSV の読み込みセル（教員提供）を実行し直します |
| カーネルが選べない | Python と VS Code の拡張機能「Python」「Jupyter」が入っているか確かめます |
| グラフが表示されない | matplotlib がありません。表示された文字の結果で確認できます（入れる場合は 5 章の手順 4） |

## 11. データについて

- `data/` の CSV は、ほとんどが**教材用の人工データ**です。実在の人・会社・ネットワークの記録ではありません。
- 各ファイルと列の意味は `data/data_dictionary.md` にあります。
- `label` 列は答え合わせのための列です。**検出のプログラムには使いません。**
- 公開されている実サーバーのログ（Loghub）は利用条件があるため、この教材には含まれていません。授業で配布された場合だけ使えます。
- 人工データでうまく検出できても、実際の環境で同じように検出できるとは限りません。

## 12. 安全上・倫理上の注意

- 許可なく実際のネットワークやコンピュータを調べる（スキャンする）ことは、不正アクセス禁止法などに違反するおそれがあります。
- データに含まれる攻撃に似た文字列（例：`<script>`）は**ただの文字列**です。実行したり、Web サイトに送ったりしてはいけません。
- CSV を表計算ソフトで開いて編集・保存しないでください（データが変わったり、文字列が数式と誤解されたりします）。
- この演習で見つけるのは「**調べる必要がある候補**」です。「攻撃者を特定した」「攻撃だと確定した」とは言えません。
