Mini Dataset（数件のデータ）は、Notebook の中に直接書いてあります。

## 人工データについて

- これらの CSV は、すべて**教材用に人工的に作ったデータ**です。実在の人・会社・ネットワーク・Web サイト・ファイルとは関係ありません。
- IP アドレスは、説明用に予約されたアドレス（`192.0.2.x`、`198.51.100.x`、`203.0.113.x`）だけを使っています。
- `label` 列は「教材として意図した答え」です。**答え合わせだけに使い、検出のプログラムには使いません。** 実際の攻撃のラベルではありません。
- 人工データでうまく検出できても、実際の環境で同じように検出できるとは限りません。

## 公開ログについて

C-1B・C-1D の Level 3 では、公開されている実サーバーのログ（Loghub）を使うことがあります。
利用条件があるため、この教材には含まれていません。**授業で教員から配布された場合だけ**使えます。
配布されたときは、一緒に配られるライセンス文（`LICENSE_LOGHUB.txt`）を読み、発表などで使うときは出典（https://github.com/logpai/loghub）を示してください。

## 注意

- C-1C のデータには、攻撃に似た文字列が**ただのテキスト**として入っています。実行したり、Web サイトに送ったりしないでください。
- CSV を表計算ソフトで開いて**編集・保存しない**でください（データが変わったり、文字列が数式と誤解されたりします）。
