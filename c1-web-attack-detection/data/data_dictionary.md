# データ辞書（学生向け）

この教材の CSV と、各列の意味です。**すべて教材用の人工データ**です（実在の記録ではありません）。

- 「型」は、Notebook の読み込みセル（`load_csv`）で変換した後の Python の型です。
- `label` 列は**答え合わせ専用**です。検出のプログラムに使ってはいけません。
- 認証の失敗、通信の多さ、ファイルの変化などは、**それだけで攻撃とは限りません**。見つかるのは「調べる必要がある候補」です。

---

## C-1A：`c1a/network_flows_tiny.csv`（42 件）

通信の記録です。1 行が 1 回分の通信のまとまり（フロー）です。**通信回数は、この行の数で数えます**（パケットの数ではありません）。

| 列 | 型 | 単位 | 意味 | 例 |
| --- | --- | --- | --- | --- |
| `record_id` | int | - | 通し番号（時刻の順） | `1` |
| `timestamp` | str | 日時 | 通信が始まった時刻 | `2026-11-20T10:04:47` |
| `src_ip` | str | - | 通信元の IP アドレス | `192.0.2.11` |
| `dst_ip` | str | - | 通信先の IP アドレス | `198.51.100.10` |
| `src_port` | int | - | 通信元のポート番号 | `57205` |
| `dst_port` | int | - | 宛先のポート番号（80 = HTTP、443 = HTTPS、22 = SSH など） | `443` |
| `protocol` | str | - | 通信の約束事（すべて `TCP`） | `TCP` |
| `packet_count` | int | 個 | パケットの数 | `32` |
| `byte_count` | int | バイト | データの量 | `3589` |
| `label` | str | - | `benign`（正常）、`portscan`（ポートスキャンを模したもの）、`dos`（通信の集中を模したもの） | `benign` |

## C-1B：`c1b/authentication_tiny.csv`（32 件）

ログイン（認証）の記録です。

| 列 | 型 | 単位 | 意味 | 例 |
| --- | --- | --- | --- | --- |
| `record_id` | int | - | 通し番号 | `1` |
| `timestamp` | str | 日時 | ログインを試した時刻 | `2026-11-20T10:06:20` |
| `user_id` | str | - | ユーザー名 | `user05` |
| `src_host` | str | - | ログインを試したコンピュータ（接続元） | `192.0.2.25` |
| `dst_host` | str | - | ログイン先のサーバー | `198.51.100.30` |
| `auth_type` | str | - | 認証の方法（すべて `password`） | `password` |
| `result` | str | - | `success`（成功）／`failure`（失敗）。**ログインの結果であって、攻撃かどうかではありません** | `failure` |
| `label` | str | - | `benign`（正常）、`bruteforce`（総当たりを模したもの）、`spraying`（パスワードスプレーを模したもの） | `benign` |

注意：入力ミスでも失敗します。また、盗まれたパスワードでのログインは「成功」として記録されます。

## C-1C：`c1c/http_requests_tiny.csv`（32 件）

Web サイトへのリクエストの記録です。

| 列 | 型 | 単位 | 意味 | 例 |
| --- | --- | --- | --- | --- |
| `request_id` | int | - | 通し番号 | `1` |
| `timestamp` | str | 日時 | リクエストの時刻 | `2026-11-20T10:00:36` |
| `src_ip` | str | - | 接続元 | `192.0.2.33` |
| `method` | str | - | `GET`（ページの取得）／`POST`（フォームの送信など） | `GET` |
| `url` | str | - | 要求されたページと入力値（`?` の後ろ） | `/search?q=keyboard` |
| `status` | int | - | サーバーの返事の番号（200 = 成功、404 = ページがない など） | `200` |
| `label` | str | - | `benign`（正常）、`sqli`、`xss`、`traversal`、`long_url`、`scan`（それぞれ攻撃に似た例） | `benign` |

注意：攻撃に似た文字列は、ただのテキストです。実行・送信しないでください。正常なリクエストにも `'` などが含まれることがあります（例：`it's`）。

## C-1C：`c1c/web_access_log_synthetic.csv`（47 件）

Web サーバーのアクセスログ（人工データ）です。「同じ接続元からのアクセスの集まり」を調べるのに使います。

| 列 | 型 | 単位 | 意味 | 例 |
| --- | --- | --- | --- | --- |
| `request_id` | int | - | 通し番号 | `1` |
| `source_line` | int | - | 元のログファイルの行番号 | `1` |
| `timestamp` | str | 日時 | 日時（日本時間 +09:00） | `2026-11-15T10:00:05+09:00` |
| `src_ip`、`method`、`url`、`status` | - | - | 上の表と同じ意味 | |
| `response_bytes` | str | バイト | サーバーが返したデータの大きさ（`load_csv` では文字列のまま） | `2048` |
| `scenario` | str | - | 教材の作成者が意図したパターン：`normal`（通常）、`access_concentration`（アクセス集中）、`error_404_concentration`（404 エラーの集中）。**攻撃の答えではありません** | `normal` |

## C-1D：`c1d/file_states_before_tiny.csv`（12 件）・`file_states_after_tiny.csv`（13 件）

ある時点で存在するファイルの一覧です（変更前と変更後）。

| 列 | 型 | 単位 | 意味 | 例 |
| --- | --- | --- | --- | --- |
| `file_id` | str | - | ファイル名（架空のもの） | `config.ini` |
| `hash` | str | - | ファイルの中身の「指紋」。**教材用の疑似ハッシュ値**で、本物のハッシュ値ではありません。中身が変わると値が変わります | `H001` |

正解ラベルはありません。追加・削除・書き換えが、すべて不正な操作とは限りません（ソフトウェアの更新などでも起こります）。

## C-1E：`c1e/data_transfer_tiny.csv`（36 件）

データを送った記録です。

| 列 | 型 | 単位 | 意味 | 例 |
| --- | --- | --- | --- | --- |
| `record_id` | int | - | 通し番号 | `1` |
| `timestamp` | str | 日時 | 送った時刻 | `2026-11-20T10:02:17` |
| `src_host` | str | - | 送った側（通信元） | `192.0.2.41` |
| `dst_host` | str | - | 受け取った側（通信先）。`203.0.113.x` は社外を想定 | `198.51.100.20` |
| `byte_count` | int | バイト | 送ったデータの量（1,000,000 バイト ≒ 1 MB） | `26615` |
| `label` | str | - | `benign`（正常）、`exfiltration`（情報の持ち出しを模したもの） | `benign` |

注意：送信量が多いこと ＝ 情報流出、ではありません（例：バックアップ）。
