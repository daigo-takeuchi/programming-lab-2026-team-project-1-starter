1. Phase 3・4 の変更のコミットの可否（現在は未コミット）。
2. 学生による試行の実施時期と対象テーマ。
3. 配布方法（非公開リポジトリ／LMS／ZIP）と、Loghub 由来データを配る範囲。
4. 旧教材ファイル（`starter.py`、`detection.py` など）の扱い（`legacy/` へ移す／配布物から除外するだけ）。
5. `TASKS.md` の【教員記入】（提出物、期限、発表時間、評価の配分）。
6. C: ドライブの空き（2.3GB）への対応（今回のプロジェクトの追加は 1MB 未満。`~/.cache` に約 570MB）。
