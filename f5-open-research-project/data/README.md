# data/：研究で使うデータ

初期デモ（線形探索 vs 二分探索）の入力は、`experiments/compare_algorithms.py` の `make_search_input` がプログラムで生成します（乱数シードを指定すれば同じデータを再現できます）。そのため、このフォルダには初期状態ではデータファイルがありません。

## データを置くときの約束

| 項目 | 約束 |
| --- | --- |
| 個人情報 | **実在の人物の個人情報（氏名・連絡先・成績など）を使わない。**必要なら架空のデータを作る |
| 出典 | 公開データを使う場合は、出典（URL・取得日）とライセンス（再配布してよいか）をこのファイルに書く |
| 大きさ | 大きいファイル（目安 10 MB 以上）はリポジトリに入れない。取得・生成の手順を書く |
| 再現性 | 乱数で作るデータは、生成プログラムとシードを記録する |
| 形式 | CSV・JSON など、Python の標準ライブラリで読める形式を推奨 |

## 実験結果の保存

`python3 -m experiments.compare_algorithms --csv results/xxx.csv` で保存した CSV は**実測値**です。実行環境（`docs/experiment_log.md`）と一緒に記録してください。`results/` は `.gitignore` に入っているので、提出する結果だけを選んでコミットします。
