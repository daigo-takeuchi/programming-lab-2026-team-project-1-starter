## 1. 演習の目的

個人や家族は、**限られた所得・時間・資産**をどう使うかを、長い期間にわたって考えます。
この演習では、そのような身近な問題を、Python の小さなプログラムに分けて考えます。

- リストと辞書でデータを表し、for 文で 1 年ずつ状態（年収・資産など）を更新する（シミュレーション）。
- 複数の選択肢（シナリオ）を作り、条件を満たすものを探す（線形探索・二分探索・全探索）。
- 結果を並べて比べる（ソート）。実行時間を測り、計算量を考える。

経済学や金融の知識を覚えることが目的ではありません。**Python とアルゴリズムで問題を解く経験**が目的です。

## 7. 進め方

1. **共通の章（第0〜3章）**を上から順に実行します。第3章の共通関数（`load_csv`・`check` など）のセルは必ず実行します。
2. **担当テーマの章（第4〜7章のどれか 1 つ）**へ進みます。他のテーマの章を実行しなくても動きます。
3. 担当テーマの Level 1・2 を終えたら、**第8章**（性能評価とチーム開発）の担当テーマの節を実行します。

## 11. よくあるエラーと対処

| 症状 | 原因と対処 |
| --- | --- |
| `NameError: name 'check' is not defined` など | 第3章のセルを実行していません。第1章から順に実行し直します |
| `NameError: name 'tiny_households' is not defined` など | 担当テーマの章の最初（N.5 のデータの読み込み）を実行していません |
| `[注意] data フォルダが見つかりません` | Notebook だけを開いています。フォルダ全体を開くか、Colab では `%cd` で教材のフォルダに移動します |
| `[NG]` で「型が違います … return を書き忘れていませんか？」 | 関数の最後に `return` がありません |
| `[NG]` で「引数（元のデータ）が書き換えられています」 | 関数の中で入力のリスト・辞書を変更しています。コピーを作るか、新しいリストに結果を入れます |
| `[エラー]` で `KeyError` | キー（列名）のつづりが違います。データの表示を見て確かめます |
| 第8章で `[スキップ]` と表示される | 他のテーマの節です。担当テーマの節だけ見ればよいです |
| グラフが表示されない | matplotlib がありません。表と文字の結果で確認できます（入れる場合は 6 章） |
| グラフの日本語が「□」になる | 日本語フォントがありません。ラベルは自動で英語に切り替わります |
