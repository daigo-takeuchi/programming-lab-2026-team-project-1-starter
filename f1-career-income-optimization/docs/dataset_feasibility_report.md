# 公開統計データの取得可能性の調査（Phase 1、2026-11-27）

- 調査方法：公式サイトのページを閲覧（データのダウンロード、アカウント登録、API キーの発行は**していない**）。
- 「未確認」は、閲覧したページで確認できなかった項目。推測で確定していない。
- **公開統計がなくても Level 1・2 はすべて実行できる**（Mini・Tiny の人工データで完結）。公開統計は Level 3（STEP 5）とチーム独自の機能だけで使う。

## 1. 共通の利用条件

| 項目 | 確認した内容 | 出典 |
| --- | --- | --- |
| e-Stat の利用規約 | 「政府統計の総合窓口（e-Stat）利用規約」。**政府標準利用規約（第2.0版）に準拠**。CC BY 4.0 と互換。商用利用可。複製・公衆送信・翻案が可能 | https://www.e-stat.go.jp/terms-of-use |
| 出典の記載 | 例「出典：政府統計の総合窓口(e-Stat)（https://www.e-stat.go.jp/）」「出典：「○○調査結果」（A省）」 | 同上 |
| 加工した場合 | 「「○○調査結果」（A省）を加工して作成」のように加工を明記。国が作成したかのように公表しない | 同上 |
| 数値データ | 数値データ・簡単な表・グラフは著作権の対象外で自由に利用できる旨の記載あり | 同上 |
| 「再配布」という語 | 規約本文に見当たらず（複製・公衆送信の許諾として読める）。**明示的な語での確認は未確認** | 同上 |
| e-Stat API | **ユーザ登録が必要**（アプリケーション ID）。料金の記載は未確認。API 利用規約は未読 | https://www.e-stat.go.jp/api/ |
| 不動産情報ライブラリ | サイトのコンテンツは公共データ利用規約（第1.0版）（PDL1.0）。出典例「出典：国土交通省　不動産情報ライブラリ」+ URL。加工した場合はその旨を記載。API は**利用申請と API キーが必要**（無償） | https://www.reinfolib.mlit.go.jp/help/termsOfUse/ |

→ e-Stat 由来の加工済み CSV は、出典と加工の記載をすれば学生配布用 CSV に**適合する見込み**（最終確認は Phase 2 で実際の表を取得した後）。

## 2. テーマ別の推奨データ（1〜2 種類に絞る）

### F-1A：賃金構造基本統計調査（厚生労働省）【第 1 候補】

| 項目 | 内容 |
| --- | --- |
| 公式 URL | https://www.e-stat.go.jp/stat-search/files?toukei=00450091 |
| 最新の調査年 | 令和7年（2025 年）。公開（更新）日 2026-06-26 |
| 統計表 | 一般労働者（産業大分類、職種、標準労働者、雇用形態別、新規学卒者 など）。**年齢階級別・学歴別の表の正式な表題は未確認** |
| 形式 | Excel（多数）、DB（e-Stat のデータベース）。表ごとの形式は未確認 |
| 単位 | 未確認（一般に月額の給与と年額の賞与が別の列になっている可能性があり、Phase 2 で確認） |
| 取得方法 | e-Stat の画面から Excel をダウンロード（登録不要の見込み）。API は登録が必要 |
| 容量 | 未確認 |
| 教材での利用 | 年齢階級別の年収（月額 × 12 + 年間賞与）を「統計にもとづく年収の推移」として、仮定値のモデルと比べる |
| 前処理 | 説明行・注記の除去、月額 → 年額（×12 + 賞与）、千円 → 万円、年齢階級の表記の統一。**難易度：中** |
| 注意 | 学歴別の差を因果効果とみなさない。平均値は個人の予測ではない |

## 4. 教員の作業が必要な事項

- e-Stat API・不動産情報ライブラリ API を使う場合は、教員がユーザ登録・API キーの取得を行う（**Phase 2 は API を使わず、画面からの Excel/CSV のダウンロードを推奨**）。
- 個別ファイルが 10MB を超える、または合計 50MB を超える取得は事前に承認を得る。
