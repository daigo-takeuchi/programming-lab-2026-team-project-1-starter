# 公開統計の前処理方針

## 1. 取得

- 公式の取得先（e-Stat の統計表ファイルのダウンロード）から、`scripts/download_datasets.py` で取得する。API（要登録）は使わない。
- 原データは `data/raw/<テーマ>/`（**Git 管理外**）。取得日時・URL・容量・SHA-256 を `data/raw/download_log.csv` に記録する。
- 1 ファイル 10MB を超えるもの、合計 50MB を超える取得は教員の承認を得る（スクリプトは 10MB 超を拒否する）。
- Web 画面の操作でしか取得できないデータ（不動産情報ライブラリの CSV）は、教員が手動で取得する。公開されていない内部の URL をスクリプトから呼ばない。

## 2. 変換

| 方針 | 内容 |
| --- | --- |
| 文字コード | 出力は UTF-8（BOM なし）、改行 LF |
| Excel の読み込み | `scripts/xlsx_reader.py`（標準ライブラリの zipfile + xml）。新しいライブラリを入れない |
| 列名 | 英語の小文字とアンダースコア。原データの区分名（学歴・年齢階級・費目）は日本語のまま別の列に残す |
| 金額 | 万円にそろえる（千円 ÷ 10、円 ÷ 10000）。**月額と年額は別の列**にし、名前で区別する |
| 年額の計算 | 「月額 × 12 + 賞与」など、**学生の課題になる計算はしない** |
| 欠損・秘匿・該当なし | 「－」「…」「...」「x」「*」は**空欄**（Notebook では `None`）。0 にしない |
| 平均値と中央値 | 使った統計表の値（今回はすべて平均値）であることを文書に書く |
| 個人と世帯 | 個人単位（賃金）と世帯単位（家計・資産）を別のファイルにし、列 `household_type` などで明示する |
| 年齢階級 | 原データの区分のまま（`age_group`）。賃金は `age_min`・`age_max` を補助として付ける（開いた区分は空欄） |
| 調査年 | `survey_year` 列に記録する |
| 出典 | `source` 列（識別名）と、`data/data_dictionary.md` の出典表示 |
| 名目値 | すべて調査年の名目値。物価の調整はしない |
| 異なる調査の組合せ | 同じ人物・世帯の追跡データとして扱わない。仮想の人物・世帯の**パラメータ**として使う |
| 性別の区分 | 使わない（性別で進路・役割を判断する教材にしないため、男女計だけを残す） |

## 3. 検証

- 前処理スクリプトは、見出し（単位の注記、列の位置、区分の名前）を確かめ、想定と違えば止まる。
- 出力は `scripts/validate_datasets.py` で検証する（必須列・型・主キー・単位の範囲・出典の有無）。

## 4. 再配布

- e-Stat の統計表（賃金構造基本統計調査、家計調査、全国家計構造調査、子供の学習費調査）は、
  「政府統計の総合窓口（e-Stat）利用規約」（政府標準利用規約 第2.0版準拠、CC BY 4.0 互換）により、
  出典の記載と加工した旨の記載をすれば複製・公衆送信・加工ができる。→ 加工した `*_small.csv` を Git 管理し、学生配布物に含めてよい。
- 不動産情報ライブラリのデータ（公共データ利用規約 第1.0版）は、取得後に条件を再確認するまで Git 管理しない予定（未取得）。
