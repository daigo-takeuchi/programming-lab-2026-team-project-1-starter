## 1. 研究テーマと目的

**F1：キャリア選択と生涯所得の最適化**（チーム課題 F「自由研究：身近な問題・社会の仕組みをアルゴリズムで考える」）

就職・転職・進学・資格取得などの選択が生涯所得に与える影響を、Python によるシミュレーションとアルゴリズムで分析します。

> **中心となる研究課題**：異なるキャリア選択によって将来の所得がどのように変化するかを定量化し、**一定の仮定と評価基準の下で**、どの選択が有利になるかを調べる。

| | 問い |
| --- | --- |
| RQ1 | **就職と進学では生涯所得がどう変わるか**（18 歳・20 歳・22 歳で就職。進学費用、進学中の所得、機会費用、昇給率） |
| RQ2 | **資格取得は生涯所得を増加させるか**（取得費用、学習期間、学習中の所得、取得後の年収変化、投資回収期間。Core では必ず成功する） |
| RQ3 | **転職する年齢によって生涯所得はどう変わるか**（転職年齢、転職後の年収・昇給率、一時費用。全探索で最大になる条件を探す） |
| RQ4 | **生涯所得の最大化と現在価値の最大化は同じか**（名目の合計、費用控除後の累積純収入、割引現在価値） |

- **Core Research（必須課題）**：Python 標準ライブラリだけで、単純化した所得モデルを作り、生涯所得・累積純収入・NPV を計算し、全探索と感度分析を行う（14章）
- **Advanced Research（発展課題）**：モンテカルロ法、動的計画法、所得以外の評価、公的統計の利用、リスクと最適化（15章）

このリポジトリにあるのは**単純な所得モデルと計算の入口**だけです。完成した経済予測モデルや人生設計アドバイザーではありません。仮定を変え、アルゴリズムを実装・比較・改良するのは学生の役割です。

## 3. 生涯所得とは何か

この教材では、次の 3 つを区別します（単位はすべて**万円**）。

| 指標 | 定義 | 関数 |
| --- | --- | --- |
| **生涯所得**（Lifetime Gross Income） | 18〜64 歳の**額面の年収**の合計 | `income_analysis.lifetime_gross_income` |
| **累積純収入**（Cumulative Net Income） | 生涯所得 − キャリア関連費用（進学費用・資格取得費用・転職費用） | `income_analysis.cumulative_net_income` |
| **割引現在価値**（NPV） | 毎年の（年収 − 費用）を、18 歳時点の価値に割り引いて合計 | `income_analysis.scenario_npv` |

> ⚠️ **所得と可処分所得は違います。** この教材の年収は**額面**（税金・社会保険料を引く前）です。実際に使えるお金（**可処分所得**、いわゆる手取り）は、所得税・住民税・社会保険料などを引いた額で、額面よりかなり少なくなります。また、ここでいう「純収入」は**キャリア関連費用だけを引いた値**で、**手取りではありません**。生活費・税・社会保険・年金・インフレ・貯蓄の運用益などは、Core では扱いません。

## 4. 年齢別所得モデル

`career_model.py`

```text
salary(a) = initial_salary × (1 + annual_growth_rate)^(a − start_age)    （start_age ≤ a < retirement_age）
salary(a) = 0                                                           （a < start_age）
```

| パラメータ | 意味 | 確認すること（違反すると例外） |
| --- | --- | --- |
| `start_age` | 就職開始年齢 | 整数、18 歳以上、退職年齢より小さい |
| `retirement_age` | 退職年齢 | 整数 |
| `initial_salary` | 初年度年収（万円） | 0 以上 |
| `annual_growth_rate` | 年間昇給率（0.02 = 2%） | −1 より大きい。絶対値が 20% を超えると**警告**（`UserWarning`） |

- **計算期間の規則**：18 歳から、退職年齢の**前の年**まで。`retirement_age = 65` なら **18〜64 歳の 47 年間**を計算し、65 歳の年からは計算対象外です（`salary_at(65, ...)` は `ValueError`）。
- 年齢別のリストは 18 歳から始まり、**i 番目が (18 + i) 歳**の値です（`index_of_age` で変換）。
- 昇給率は毎年一定です（実際には年齢によって変わる。TODO）。

## 5. 進学と機会費用

`scenarios.university`、`data/sample_careers.json` の `university`・`vocational`

- **進学費用**（直接費用）：`education_cost` を、進学期間（18 歳〜就職の前年）の各年に**均等に**支払うと仮定します（400 万円・4 年なら毎年 100 万円）。
- **機会費用**：進学している間、働いていれば得られたはずの所得（18 歳で就職した場合の 18〜21 歳の年収）を失います。この教材では、進学中の所得を 0 としているので、機会費用は「比較対象のキャリアとの累積純収入の差」として自然に現れます。
- **進学による賃金上昇の仮定**：架空データでは、22 歳就職の初年度年収（330 万円）と昇給率（2.5%）を、18 歳就職（250 万円・2%）より高く設定しています。**これは教育用の仮定であり、進学の因果効果を示すデータではありません。** この仮定を変えると結論が変わります（Experiment 1・5）。
- **投資回収年齢**：累積純収入が比較対象（18 歳就職）に追いつく最初の年齢（`income_analysis.payback_age`）。

## 6. 資格取得の費用対効果

`scenarios.certificate`

- 取得する年齢 `age` に費用 `cost` を支払い、**取得の翌年から**毎年 `salary_increase` 万円、年収が増えると仮定します。
- 学習期間 `study_years` と、学習中の年収の割合 `study_income_ratio`（1.0 = 減らない）を設定できます（既定では学習中も年収は減らない）。
- **Core では資格取得は必ず成功します。** 成功確率（不合格なら費用だけかかる）は Advanced A の課題です。
- 投資回収年齢は、**同じキャリアで資格を取らない場合**と比べて求めます（`with_changes(s, certificate=None)`）。

## 7. 転職と所得変化

`scenarios.job_change`

- 転職年齢 `age` から、転職後の年収 `new_salary × (1 + growth_rate)^(a − age)` に置き換わり、その年に一時費用 `cost` を支払います。
- **Core の重要な仮定**：転職後の初年度年収は、**転職する年齢・それまでの経験によらず一定**です。そのため、架空データ（420 万円）では**早く転職するほど有利**になり、最適な転職年齢は候補の最小値（22 歳）になります。これは**モデルの仮定から出てくる結果**であり、「早く転職すべき」という結論ではありません。経験に応じて転職後の年収が変わるモデルにするのは学生の課題です（Experiment 3 の TODO）。
- 遅い年齢での転職では、転職前の年収（昇給を重ねた額）が 420 万円を上回るため、転職すると所得が**下がる**ことがあります。全探索の候補には「転職しない」が含まれていないことにも注意してください（TODO 3-0）。

## 8. 累積所得と現在価値

### 累積所得・累積純収入

```text
Lifetime Gross Income  = Σ_a annual_salary(a)
Cumulative Net Income  = Total Salary Income − Career-related Costs
```

### 割引現在価値（NPV）

```text
NPV = Σ_t CashFlow_t / (1 + r)^t
```

- `CashFlow_t`：各年の年収 − その年のキャリア関連費用
- `t`：基準年（18 歳）からの経過年数（18 歳は t = 0 で割り引かない）
- `r`：割引率。初期値は **3%（架空の例）**。`data/sample_careers.json` の `settings.discount_rate` や、関数の引数で変更できます。

**割引の意味**：今の 100 万円と 30 年後の 100 万円は同じ価値ではない（今のお金は使える・増やせる・不確実性が小さい）、という考え方です。割引率が高いほど、**遠い将来の所得の価値が小さく**なり、「早く稼ぎ始める」キャリアが相対的に有利になります。

- 割引率 0% の NPV は累積純収入と一致します（テストで確認）。
- **RQ4**：架空データでは、生涯所得・累積純収入の順位と、NPV（3%・5%）の順位が一部入れ替わります（13章の出力、Experiment 4）。

## 9. 全探索による最適化

`optimization.py`

1. 転職年齢の候補を列挙する（`switch_age_candidates`：22〜60 歳のうち、就職後・退職前の年齢）。
2. 各候補について、シナリオの**コピー**の転職年齢だけを変えて（元のシナリオは変更しない）、生涯所得・累積純収入・NPV を計算する（`evaluate_switch_ages`）。
3. 評価基準ごとに最大値を与える候補を選ぶ（`optimal_switch_ages`）。
   - 教科書の `max_of` で最大値を求め、教科書の `seq_search` でその値が**最初に現れる位置**を探します。
   - **同点の規則**：同じ最大値が複数あるときは、**候補リストで最初に現れるもの**（昇順の候補なら**最も若い転職年齢**）を選びます。
4. 候補が空なら、最適解は `None` です。

**生涯所得最大・累積純収入最大・NPV 最大は、別々に求めます。** 条件によっては、これらの最適な転職年齢が異なります（Experiment 3 の 2 つ目の条件では、生涯所得最大は 22 歳、NPV 最大は 60 歳）。

## 10. 理論計算量

T = 計算する年数（18〜64 歳なら 47）、N = キャリアの数、K = 転職年齢の候補の数とします。

| 処理 | 計算量 | この教材 |
| --- | --- | --- |
| 1 つのキャリアの年齢別所得 | **O(T)** | `career_model.income_by_age`（年齢ごとに 1 回計算） |
| 生涯所得・累積純収入・NPV | **O(T)** | リストを 1 回たどる |
| N 個のキャリアの比較 | **O(NT)** | 各キャリアを T 年分計算 |
| 転職年齢の全探索 | **O(KT)** | K 個の候補 × T 年。この教材では K = 39、T = 47 |
| 最大値探索 | **O(K)**（N 個なら O(N)） | `max_of` + `seq_search`（各 O(K)） |
| ソートによる順位付け | 比較ソートでは **O(N log N)** が代表的 | この教材は教科書の単純挿入ソート（**O(N²)**、N が小さいので十分） |
| 転職 2 回の全探索 | O(K² T) | TODO（→ 動的計画法） |

> **理論計算量と実際の処理時間は別のものです。** 計算量は「問題が大きくなったときの増え方」を表し、実際の時間は実装・Python の速さ・コンピュータによって決まります。この教材の規模（K = 39、T = 47）では、全探索は一瞬で終わります。全探索が問題になるのは、選択の組合せが増えたとき（転職・資格・進学を毎年選べる、など）です。

### 教科書との対応

1. **配列による年齢別所得の管理**：年齢別の年収をリスト（配列）に入れ、添字 = 年齢 − 18 で管理します（第2章 配列）。費用・キャッシュフロー・累積値も同じ長さのリストです。
2. **ループによる累積所得の計算**：for ループで 1 年ずつ足していく（`income_analysis.total`・`cumulative`）。教科書第2章の「配列の要素の合計」と同じ考え方です。
3. **最大値探索による最適な転職年齢の探索**：各候補の評価値を配列に入れ、教科書の `max_of`（第2章）で最大値を求め、`seq_search`（第3章 線形探索）でその位置を探します。O(K) + O(K)。
4. **ソートによるキャリア選択肢の順位付け**：(−評価値, 元の番号) の組を教科書の単純挿入ソート（第6章）で並べます。安定なソートなので、同点の場合は元の順番が保たれます。
5. **全探索の計算量**：転職年齢 K 通り × T 年 = O(KT)。選択が増えると候補の数は掛け算で増え（転職 2 回なら K²、毎年 c 通りの選択なら c^T）、全探索はすぐに現実的でなくなります。
6. **動的計画法への発展可能性**：「年齢 a のときの状態（職種・資格の有無など）」ごとに「それ以降に得られる最大の価値」を表にして、高い年齢から順に埋めると、毎年の選択の組合せ（c^T 通り）をすべて試さずに、O(T × 状態数 × 行動数) で最適な行動系列を求められます。教科書第5章の**メモ化**（同じ計算の結果を覚えて再利用する）と同じ発想です（Advanced B）。

## 15. Advanced Research

Core Research を終えたチームが取り組む課題です。**Advanced A〜E のうち 1 つ以上を選択**してください。すべてを実装する必要はありません。

### Advanced A：モンテカルロシミュレーション

- 昇給率を確率変数にする（例：毎年 `rng.gauss(0.02, 0.01)`）。
- 転職後の年収を確率変数にする。
- 資格取得の成功確率を設定する（不合格なら費用だけかかる、再受験する、など）。
- 複数回（例：10,000 回）シミュレーションし、平均生涯所得を計算する。
- 所得の分布を可視化する（ヒストグラム）。
- 下振れリスク（例：下位 10% の値、ある金額を下回る確率）を評価する。
- **乱数シードを固定**できるようにする（`random.Random(seed)`）。シードを報告に書く。

### Advanced B：動的計画法

- キャリアを**状態**として表現する（例：(職種, 資格の有無, 経験年数)）。
- 年齢を**時間ステップ**とする。
- 就職・転職・進学・資格取得を**行動**として表現する。
- **状態遷移**（ある状態で行動を選ぶと、次の年の状態がどうなるか）を定義する。
- 各行動の**費用と所得**を定義する。
- 高い年齢から順に「その状態からの最大の価値」を表に埋め、**最適な行動系列**を求める。
- 全探索（行動の組合せすべて）と計算量を比べる。

> Core では動的計画法の完成したコードは提供しません。状態・行動・遷移の設計から自分たちで考えてください。

### Advanced C：所得以外の評価

- 労働時間、休日、仕事の満足度、健康への影響、失業リスク、家族との時間などを指標に加える。
- **複数目的の最適化**として扱う：重み付き和（重みの決め方とその影響）、パレート最適（どの指標でも他より悪くない選択肢の集合）。
- 指標の数値化には主観が入ることを明記する。

### Advanced D：現実の統計データ

利用を検討できる公的統計の例：

- 厚生労働省「賃金構造基本統計調査」（年齢・学歴・職種などの区分別の賃金）
- 総務省統計局「労働力調査」（就業・失業の状況）
- 文部科学省「学校基本調査」（進学・就職の状況）
- 政府統計の総合窓口 **e-Stat**（上記を含む各種統計の検索・ダウンロード）

実際に利用する場合は、**調査年、対象集団、単位（月額・年額、所定内給与か年収か、など）、出典（URL と参照日）**を必ず明記してください。

> ⚠️ **観察された学歴別・職業別の賃金の差を、進学や資格取得の「因果効果」と同一視しないでください。** 差には、進学する人としない人のもともとの違い（選択バイアス）、時代・地域・産業の違いなどが含まれます。統計は「平均的な傾向」であり、個人の将来を予測するものでもありません。

### Advanced E：リスクと最適化

- 期待生涯所得（平均）、所得の分散（ばらつき）、失業確率、下振れリスクを計算する（Advanced A と組み合わせる）。
- **リスク回避度**を考える：同じ期待値なら、ばらつきの小さい方を好む人がいる（例：期待値 − λ × 標準偏差 で評価）。
- 複数の評価基準で順位を付け、**期待所得が最大のキャリアと、リスクを考慮した最適キャリアが異なる**可能性を調べる。

## 17. モデルの限界と倫理的配慮

- **本教材は教育用シミュレーションです。** 架空の年収・費用を使っています。
- **将来の所得を予測・保証するものではありません。** 昇給率が毎年一定、転職後の年収が経験によらない、などの強い単純化をしています。
- **税・社会保険料・年金・インフレ・失業・病気・物価・投資収益は扱っていません。** 所得（額面）と可処分所得（手取り）は異なります。
- **学歴・資格・転職の効果は、個人や社会状況（時代・地域・産業・景気）によって異なります。** この教材で置いた「進学すると年収が上がる」などは仮定にすぎません。
- **所得だけで人生の価値を評価しないでください。** やりたいこと、学ぶこと自体の価値、健康、家族や友人との時間、社会への貢献など、所得では測れないものがあります（Advanced C）。
- **性別、国籍、出身地、障害の有無などによる差別的な意思決定を推奨しません。** 統計上の属性間の差を、個人の能力や進路を決める根拠にしないでください。属性を入力に使うモデルは、差別を再生産するおそれがあります。
- **実際のキャリア相談や投資助言の代わりにはなりません。** 進路は、学校の先生、キャリアセンター、家族などと相談してください。
- **現実の統計を使う場合は、相関と因果関係を区別してください**（Advanced D）。
