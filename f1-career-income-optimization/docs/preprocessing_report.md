## 1. F-1A `data/f1a/salary_by_age_small.csv`（84 行 × 12 列、約 8KB）

| 項目 | 内容 |
| --- | --- |
| 原データ | `data/raw/f1a/wage_census_2025_education_age.xlsx`（1,542,010 バイト。e-Stat statInfId=000040420843） |
| 統計 | 厚生労働省「令和7年賃金構造基本統計調査」（調査年 2025 年。公開日 2026-03-24） |
| 統計表 | 一般労働者 産業大分類「学歴、年齢階級別きまって支給する現金給与額、所定内給与額及び年間賞与その他特別給与額（産業計・産業別）」の「産業計」シート |
| 対象集団 | 一般労働者、民営事業所、企業規模計（10 人以上）、産業計、**男女計** |
| 取り出した区分 | 学歴 7 区分（学歴計・中学・高校・専門学校・高専・短大・大学・大学院）× 年齢階級 12 区分。学歴「不明」と性別の行は除外 |
| 列 | 平均年齢（歳）、きまって支給する現金給与額・所定内給与額（**万円／月**）、年間賞与その他特別給与額（**万円／年**）、労働者数（十人） |
| 単位の変換 | 千円 → 万円（÷10、小数 2 桁） |
| 欠損 | 34 個の空欄：開いた年齢階級の `age_min`（～19 歳）・`age_max`（70 歳～）14 個、原データの「－」（大学・大学院などの 19 歳以下）20 個 |
| 学生が行う計算 | 年収の目安 = 月額 × 12 + 年間賞与（統計上の定義の違いは Notebook 4.9 に記載） |
| 注意 | 横断的な（同じ年の異なる年齢の人の）平均。同じ人の生涯の追跡データではない。学歴の差は因果効果ではない |
